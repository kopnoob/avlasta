About this page

  • A scheduled job at GitHub calls the demo's health check about every 15 minutes. GitHub may delay or skip runs when busy, so the gap can be longer.
  • The demo counts as up when the health check replies within 20 seconds and reports that both the app and the database work. Response time includes start-up when the demo has been idle.
  • The status page is hosted by GitHub and the demo by Netlify, so this page works when the demo is down. Both are US services, so this is not yet an independent measurement.
  • We only store the time, whether the check passed, and the response time. The data is in an open file.

Seeing errors in the demo that do not show here? Email kopstad@commit.no. The checks are available as JSON.
