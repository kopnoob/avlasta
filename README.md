# Avlasta, offentlig nettside

Dette repoet inneholder bare de publiserte sidene for Avlasta (https://kopnoob.github.io/avlasta/). Avlasta leveres av Commit AS, org.nr. 934 427 688.

Statussiden oppdateres av en planlagt jobb i `.github/workflows/publiser.yml`, som leser demoens helsesjekk og publiserer siden på nytt.

Skriften Inter er lisensiert under SIL Open Font License (`assets/fonts/OFL-inter.txt`).
